# Historical product documents

This directory preserves the former product-contract program and early planning references as of the Phase 0 consolidation on 2026-07-20.

The material remains useful for decision history, edge cases, and future feature analysis. It is not the active implementation roadmap and must not be read as a requirement to implement every recorded invariant before shipping a vertical feature slice.

The active source of truth is [Current product contract](../product-contract.md).

## Contents

- `02` through `13`: previously approved phase contracts.
- `14`: the support-case draft as it existed at consolidation.
- `domain-glossary.md`: the former cumulative glossary and invariant register.
- `backend-roadmap.md`: early Supabase table suggestions.
- `system-overview.md` and `system-overview.txt`: early product overview copies.

Links among the historical phase files remain relative within this directory. When a historical rule conflicts with the current product contract or implemented behavior approved in a later vertical phase, the later source controls.
